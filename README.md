# 证道白金（Platinum）

> 桌面端 AI 小说写作助手——**作者主导**，AI 协作，正文永远由你掌控。

基于 [goink](https://github.com/sigpanic/goink)（AGPL-3.0）二次开发，保留上游历史与版权声明。

---

## 核心特点

**1. 正文保护（与同类最大的不同）**
AI 无法直接修改正文——所有 AI 输出先进「草稿」，你确认后才发布到正文。正文是你的独属区域，AI 只能建议、不能动笔。

**2. 数据安全三保险**
- 每部小说独立 git 仓库，改一次存一版，可随时回滚；
- 回收站两段式删除（删了先进回收站，二次删除才清除）；
- 定时自动存档（默认 30 分钟），恢复前自动备份当前状态。

**3. 省 token 的智能写作**
- **破甲词**：每本书设定专属指令，AI 每次运行最先执行，约束稳定；
- **维护范围**：告诉 AI 该管哪些（角色/时间线/大纲/故事状态文档等），不相关的领域不读不写，大幅省 token；
- **文风库**：从你的素材提取写作风格，AI 按你的文风写；提取过程实时可视化（思考/生成全可见）；
- **章节定位省 token**：说「编号006」直达，说「第X章」先查标题再读正文。

**4. 可视化世界管理**
- **沙盘**：多份命名画布，把地点/角色/事件/小说设定拖进去摆位置——形状自由摆放（移动/旋转/缩放/配色/文字/框选整组移动），点击形状直达完整页面；
- **AI 布局**：聊天说"把设定摆到沙盘上""在X北边新建Y""把A、B放到C旁边"，AI 自动理解并布局（含删除/移动/新增/批量/歧义反问）；也可用工具栏「AI 布局」一键按设定生成——**布局在后台运行，可随时关闭弹窗切换到其他页面，完成后弹窗通知；也可点击「取消布局」随时中止**；新用户首次进入沙盘会弹出简洁使用指南；
- **比例尺与嵌套**：地点按描述尺寸等比缩放（最小=基准），"放到X上/里"自动塞进图形内部，人物/事件按金字塔排列不重叠；
- **小说设定实体**：设定条目可放入沙盘（井字地图容器），世界观层级（设定→地点→角色/事件）可展开；
- **自动保存兜底**：正文/草稿/大纲停止输入自动保存，沙盘停止操作自动保存，关进程强制落盘 + 历史归档（零丢失）；
- 角色关系图、地点图谱、时间线、叙事弧线、读者认知（悬念/误解）全覆盖。

**5. 顺手的产品细节**
- 便携：数据默认在程序文件夹，整个文件夹拷走即迁移；也可自由选择数据目录（选择记录在程序文件夹内，改后立即生效）；
- 四视图并列：正文 / 草稿 / 用户大纲 / AI总结大纲，历史版本保留；
- 卷 + 章节编号体系：拖拽排序不改编号，导出顺序清晰；
- **八套主题**（浅色/深色/护眼/黑黄高对比/浅粉/暖灰/淡蓝灰/浅黄）：右上角一键循环快速切换前四套；
- **自定义主题**（整个界面）：边框色/系统文字色/背景色/全局字体/全局字号，改完立即生效，可保存为独立配色方案（最多 10 套）；
- **自定义编辑器**（正文区）：编辑器文字/背景色，与字号/字体/行距一起保存生效，可保存为独立配色方案（最多 10 套）；
- **防呆保护**：恢复默认按钮常驻黑底白字；若文字与背景对比度过低，右下角自动浮现「恢复默认」救援按钮，永不锁死；
- 全中文界面，帮助对话框内置完整说明。

## 快速上手

1. **首次启动**：选择数据目录（默认程序所在文件夹即可）→ 进入主界面。
2. **开始写作**：左侧书架 → 新建/导入小说 → 点章节开始写（新书自带第一章）。
3. **让 AI 帮忙**：
   - 右侧聊天框直接说需求（"写第三章草稿""润色这段"）；
   - AI 输出进**草稿**，点「导入正文」确认后发布；
   - 不满意随时「对比正文」或回滚历史版本。
4. **设定你的 AI**：书名下「AI 设定」→ 破甲词、注入开关、维护范围。
5. **管理世界**：左侧活动栏——角色/地点/时间线/弧线/沙盘，逐步填充世界观。

> 详细操作见软件内「帮助」（右上角 ? 图标），覆盖全部 AI 工具说明。

## 数据目录

- **默认**：程序所在文件夹（便携，整个文件夹拷走即迁移）；
- **自定义**：设置 → 通用 → 数据目录，点文件夹图标选择其他位置，立即生效；
- 选择记录在程序文件夹内的 `data_dir.txt`，不写入系统全局配置。

## 技术栈与构建（开发者）

Go + Wails v2 + React + TypeScript + SQLite + ONNX Runtime（本地向量检索）。

```powershell
$env:CGO_CFLAGS = "-I<包含 sqlite3.h 的目录>"
wails build
```

脚本：`scripts/build_windows.ps1`、`scripts/deploy_windows.ps1`（部署 + 自动版本备份）。
